CHIRAL SU(5): REFLECTION-POSITIVITY DEPENDENCY TRACE
Finalized 25 November 2026; source inspection 24 November 2026

Finding
The route used by the final theorem proves exact reflection positivity for
restricted, buffered tests of an auxiliary finite-regulator functional. It
compares the actual finite-regulator expectations to that auxiliary functional
with an error tending to zero as the UV cutoff is removed. Positivity is then
passed to common limiting expectations and finally expressed as Gram positivity
for the selected continuum state's admissible positive-slab words.

This route does not establish exact full-field reflection positivity of the
original chiral lattice theory at each finite regulator. Positivity for admitted
supports can already be stated after the UV limit at fixed volume (Tower/Reflect,
I_axial), before the subsequent volume limit and continuum reconstruction.

Key distinctions in the source
* Ignite: X_s uses the actual trajectory .X; Z_s uses the auxiliary donor .Q.
  compass/listen read X_s; solder/collector read Z_s.
* Smokestack: Metered.fund is positivity for AtSupport false on a buffered band,
  not an unrestricted full Weyl-field algebra.
* Roll: sharp uses listen; hot uses collector. rate bounds their difference by
  any positive tolerance eventually in the cutoff. both gives common limits.
* Praise: lamp passes positivity through the UV and period limits using
  ge_of_tendsto twice; matrix gives the resulting finite-family PSD statement.
* Tower/Upright -> Tower/Ark -> Selected/Vacuum build the common Hilbert-space
  hierarchy from these limiting positive forms.
* Aria/Legion: duo_positive identifies the selected state's reflection matrix
  with a Gram matrix on the restricted Posy domain.
* SU5RelativisticProof supplies its reflectionPositive field using duo_positive.

Interpretive limit
This is a focused reading of the formal proof route, not an independent audit
that the auxiliary-to-actual matching and observable definitions faithfully
capture the intended physical overlap Weyl theory. It explains why finite-spacing
nonpositivity of the full overlap Weyl field algebra does not by itself contradict
this formal continuum RP claim. The observable correspondence remains to be audited.
